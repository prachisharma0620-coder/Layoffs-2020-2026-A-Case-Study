# Tech Layoffs 2020–2026 | EDA Project

A data analysis project investigating global tech layoff patterns using Python.  
Built as part of my Business Analyst portfolio.

## Dataset
- **Source:** [layoffs.fyi](https://layoffs.fyi) via Kaggle  
- **Size:** 4,361 records across 11 columns  
- **Period:** March 2020 – April 2026

## Tools Used
`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn`

## Business Questions Answered

| # | Question |
|---|----------|
| 1 | Which year saw the most layoffs? |
| 2 | Which industries were hit hardest? |
| 3 | Which companies cut the most? |
| 4 | Which countries were most affected? |
| 5 | Is there a seasonal layoff pattern? |
| 6 | Does funding protect against layoffs? |
| 7 | Which funding stage is most vulnerable? |
| 8 | How did industry impact shift year over year? |
| 9 | Which industries cut the deepest % of workforce? |

## Key Findings
- 2023 was the worst year (264K layoffs) — not 2022 as widely reported
- India ranks #2 globally — largely US company Indian offices, not Indian firms
- Amazon led absolute cuts; Intel's signal structural, not cyclical decline
- Funding raised has near-zero correlation (0.12) with layoff severity
- January consistently spikes every year — layoffs are timed around bonus cycles
- Post-IPO companies account for 70%+ of all layoffs — shareholder pressure effect
